# Семинар 10. Проверка email при регистрации

В первом задании нужно провести небольшую фичу через issue, отдельные ветки, Pull Request, ревью и слияние в GitHub. Фича проверяет формат email при регистрации.

## Запуск

Нужен Python 3. Запуск из папки проекта после объединения кода и тестов:

```bash
python3 -B registration.py
python3 -B -m unittest -v
```
